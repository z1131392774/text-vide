# text-vide (Backend / Library Core)

> Library-level conventions for the `text-vide` package — a Bionic Reading text transformation library.

---

## Overview

`text-vide` is a pure TypeScript library that transforms text by adding artificial fixation points (highlighting leading characters of words). It is published as an NPM package with ES, CJS, and IIFE builds.

## Key Conventions

- **Entry point**: `src/index.ts` — re-exports `textVide` as named export, internal modules are default-exported
- **Build**: Vite library mode → `dist/index.js` (CJS), `dist/index.mjs` (ES), IIFE
- **Type definitions**: Generated by `vite-plugin-dts` → `dist/packages/text-vide/src/index.d.ts`
- **Testing**: Vitest with `describe`/`it`/`expect` pattern, no mocking library
- **Workspace deps**: `utils` → `defaults`, `isEmpty`, `omitBy`; `tsconfig` → shared TS config
- **CJK support**: Since v1.9, CJK text is detected via Unicode script property (`\p{sc=Han}` etc.) and chunked into 8-12 char groups before applying bold ratio
- **Bold strategy**: Percentage-based (40%) replaces original fixation boundary table since v1.9
- **Language**: All documentation should be written in **English**.
